## 快速入门

### 什么是玄语？

玄语（Xuanyu）是一门中文原生的编程语言，专为自举设计，使用中文关键字和标识符，消除非英语母语者的认知摩擦。

### 环境准备

玄语使用 Rust 编写的 L1 编译器进行编译。首先需要构建 L1 编译器：

```powershell
# 在项目根目录执行
cargo build --release

# 生成的编译器位于 target\release\xy.exe
```

### 第一个程序

创建文件 `hello.xy`：

```玄语
/**
 * 我的第一个玄语程序
 */
函数 主(): 整数 {
    打印("你好，玄语！")
    打印("\n")
    返回 0
}
```

### 编译和运行

使用 L1 编译器编译你的程序：

```powershell
# 直接编译并运行
cargo run -- examples\hello.xy --run

# 仅生成 LLVM IR（默认带调试信息）
cargo run -- examples\hello.xy --ir

# 将 IR 写入指定文件
cargo run -- examples\hello.xy --ir-file output.ll

# 编译生成可执行文件
cargo run -- examples\hello.xy --build

# 使用编译后的二进制
.\target\release\xy.exe examples\hello.xy --run
```

输出：
```
你好，玄语！
```

## 控制流

### 条件判断 - 若/否则

```玄语
函数 主(): 整数 {
    定义 分数: 整数 = 85
    
    若 分数 >= 90 则 {
        打印("优秀\n")
    } 否则 若 分数 >= 60 则 {
        打印("及格\n")
    } 否则 {
        打印("不及格\n")
    }
    
    返回 0
}
```

### 循环 - 当

```玄语
函数 主(): 整数 {
    定义 可变 计数: 整数 = 1
    
    当 计数 <= 5 则 {
        打印("第 ")
        打印整数(计数)
        打印(" 次循环\n")
        计数 = 计数 + 1
    }
    
    返回 0
}
```

### 循环 - 无限循环

```玄语
函数 主(): 整数 {
    定义 可变 计数: 整数 = 0
    
    循环 {
        打印整数(计数)
        打印("\n")
        计数 = 计数 + 1
        
        若 计数 >= 5 则 {
            退出  // 跳出循环
        }
    }
    
    返回 0
}
```

### 跳转语句

- `退出`：跳出当前循环
- `跳过`：跳过当前循环剩余部分，进入下一次迭代
- `返回`：从函数返回

### 模式匹配 - 匹配/情况

`匹配` 语句用于对枚举变体进行多路分支判断，支持字段绑定和默认兜底分支。

```玄语
枚举 颜色 { 红, 绿, 蓝 }

函数 主(): 整数 {
    定义 颜色值 = 红
    定义 可变 结果: 整数 = 0

    匹配 颜色值 {
        情况 红 => { 打印("红色") 结果 = 1 }
        情况 绿 => { 打印("绿色") 结果 = 2 }
        情况 蓝 => { 打印("蓝色") 结果 = 3 }
        默认 => { 打印("未知") 结果 = 0 }
    }
    打印整数(结果)
    返回 0
}
```

**说明**：
- `情况` 分支按顺序匹配，命中后执行对应分支体
- `默认` 分支在所有显式分支未命中时执行
- 支持 `=>` 箭头语法，分支体放在 `{ }` 中

## 函数

### 函数定义

使用 `函数` 关键字定义函数：

```玄语
/**
 * 计算两个整数的和
 * @param 甲 第一个整数
 * @param 乙 第二个整数
 * @return 两数之和
 */
函数 相加(甲: 整数, 乙: 整数): 整数 {
    返回 甲 + 乙
}
```

### 函数调用

```玄语
函数 主(): 整数 {
    定义 结果: 整数 = 相加(3, 5)
    打印整数(结果)  // 输出: 8
    打印("\n")
    返回 0
}
```

### 无返回值函数

使用 `无返回` 作为返回类型：

```玄语
函数 问候(姓名: 文本): 无返回 {
    打印("你好，")
    打印(姓名)
    打印("！\n")
}
```

### 递归函数

玄语支持递归调用：

```玄语
/**
 * 计算阶乘
 */
函数 阶乘(数值: 整数): 整数 {
    若 数值 <= 1 则 {
        返回 1
    }
    返回 数值 * 阶乘(数值 - 1)
}

函数 主(): 整数 {
    定义 结果: 整数 = 阶乘(5)
    打印整数(结果)  // 输出: 120
    打印("\n")
    返回 0
}
```

### 主函数

程序入口点必须是名为 `主` 的函数：

```玄语
函数 主(): 整数 {
    // 程序代码
    返回 0
}
```

主函数通常返回 `整数` 类型，0 表示成功退出。

## 异步编程

玄语 v0.3.0 支持基于轻量协程的异步编程。使用 `异步` 声明异步函数，`启动` 将函数注册为协程任务，`等待` 等待任务完成并获取结果。

### 基本语法

```玄语
// 声明异步函数
异步 函数 异步任务(名称: 文本, 次数: 整数): 整数 {
    定义 可变 总和 = 0
    循环 从 i 到 次数 {
        总和 = 总和 + i
    }
    返回 总和
}

// 启动并等待
函数 主(): 整数 {
    定义 任务一 = 启动 异步任务("任务一", 10)
    定义 任务二 = 启动 异步任务("任务二", 20)

    定义 结果一 = 等待 任务一   // → 55
    定义 结果二 = 等待 任务二   // → 210
    打印整数(结果一 + 结果二)   // → 265
    返回 0
}
```

### 关键字

| 关键字 | 英文别名 | 说明 |
|--------|----------|------|
| `异步` | `async` | 声明异步函数（放在 `函数` 前） |
| `启动` | `spawn` | 启动协程任务，返回 i64 句柄 |
| `等待` | `await` | 等待协程完成，返回任务结果 |

### 工作原理

1. 编译器为每个 `异步` 函数生成协程包装器（`i64(i64)` ABI）
2. `启动` 将参数打包为结构体，调用 `rt_coro_spawn` 注册协程
3. `等待` 调用 `rt_coro_await` 运行协程到完成并获取结果
4. Runtime 协程调度器负责管理协程生命周期

### 限制

- `启动` 只能用于 `异步` 声明的函数
- 协程为 run-to-completion 模型，当前不支持挂起/恢复

## 调试器

v0.3.0 提供运行时调试支持。使用 `--debug` 编译的程序会在每条语句前注入断点陷阱，支持交互式单步执行。

### 启用调试

```bash
# 编译调试版本
xy program.xy --debug --build

# 运行（进入调试交互模式）
./output.exe
```

### 调试命令

在 `(xy-dbg)` 提示符下：

| 命令 | 功能 |
|------|------|
| `s` / `单步` / `step` | 单步执行下一条语句 |
| `c` / `继续` / `continue` | 继续执行到下一个断点 |
| `q` / `退出` / `quit` | 退出程序 |
| `h` / `帮助` / `help` | 显示帮助 |

### 调试模式输出

```bash
xy program.xy --debug --ir    # 查看行号映射表
xy program.xy --debug         # 查看行号映射（不执行）
```

## 编译与运行

### 使用 L1 编译器

目前阶段，使用 Rust 实现的 L1 编译器进行编译。

#### 编译步骤

```powershell
# 1. 编译并直接运行
cargo run -- 输入文件.xy --run

# 2. 仅生成 LLVM IR，写入指定文件
cargo run -- 输入文件.xy --ir-file 输出文件.ll

# 3. 编译生成可执行文件并运行
.\target\release\xy.exe 输入文件.xy --build
.\输出文件.exe
```

### 完整示例

创建 `计算.xy`：

```玄语
/**
 * 计算两数之和
 */
函数 相加(甲: 整数, 乙: 整数): 整数 {
    返回 甲 + 乙
}

函数 主(): 整数 {
    打印("请输入第一个数：")
    定义 数1: 整数 = 输入整数()
    
    打印("请输入第二个数：")
    定义 数2: 整数 = 输入整数()
    
    定义 结果: 整数 = 相加(数1, 数2)
    
    打印("结果：")
    打印整数(结果)
    打印("\n")
    
    返回 0
}
```

编译并运行：

```powershell
# 直接编译并运行
cargo run -- 计算.xy --run
```

## 最佳实践

### 命名规范

- 使用有意义的中文命名
- 函数名使用动词开头（如：计算、获取、打印）
- 变量名使用名词
- 避免使用单字母变量（循环变量除外）

### 代码风格

- 使用 2 空格缩进
- 大括号 `{` 放在行尾
- 函数之间空一行
- 添加必要的注释说明

### 示例

```玄语
/**
 * 计算斐波那契数列第 n 项
 */
函数 斐波那契(n: 整数): 整数 {
    若 n <= 1 则 {
        返回 n
    }
    返回 斐波那契(n - 1) + 斐波那契(n - 2)
}

函数 主(): 整数 {
    定义 可变 索引: 整数 = 0
    
    当 索引 < 10 则 {
        打印("斐波那契(")
        打印整数(索引)
        打印(") = ")
        打印整数(斐波那契(索引))
        打印("\n")
        索引 = 索引 + 1
    }
    
    返回 0
}
```

## 常见问题

### Q: 如何调试玄语程序？

A: v0.3.0 提供了 `--debug` 模式和运行时断点陷阱。编译时使用 `xy program.xy --debug --build`，运行时支持单步(s)、继续(c)、退出(q) 交互命令。也可以通过添加 `打印` 语句输出中间值。

### Q: 玄语支持异步编程吗？

A: v0.3.0 支持！使用 `异步 函数` 声明异步函数，`启动` 注册协程任务，`等待` 获取结果。详见[异步编程](#异步编程)章节。

### Q: 玄语支持面向对象吗？

A: 当前版本主要关注语言基础设施（模式匹配/异步/调试器），面向对象特性将在后续版本中添加。

### Q: 可以调用 C 语言函数吗？

A: 可以！使用 `外部` 关键字声明外部函数：

```玄语
外部 函数 外部函数名(参数: 类型): 返回类型
```
