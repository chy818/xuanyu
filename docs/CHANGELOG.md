# 玄语编译器 v0.2.0-beta 发布说明

## 开发版更新（v0.3.0 准备期，未发布）

本段记录为 v0.3.0（模式匹配 / 异步 / 调试器 / 发布包）做准备的开发变更，尚未打版本号。

### 新增
- **模式匹配最小可用 codegen**：`匹配` 语句（枚举变体 `icmp eq` 判别链 + 字段绑定 + `默认` 分支）已可实现，配套 e2e 测试接入 CI
- **协程调度器原语（runtime）**：`rt_coro_spawn/resume/await/tick/run_all` 等 C 基座已加入 runtime.c，供异步状态机使用
- **`等待` codegen 接线**：`Expr::Await` 从透传升级为调用 `rt_coro_await`（i64 协程句柄等待结果）
- **调试器骨架**：CLI 新增 `--debug` 标志输出「源码行号 → 函数」映射；REPL 新增 `:断点`/`:继续`/`:单步` 命令占位
- **发布打包脚本**：`build/release.ps1` 产出 `dist/xuanyu-<版本>/` 分发目录与 zip，含 xy / runtime.c / xyc.xy / 示例 / 文档 / VERSION，并在打包后自检
- **版本号统一**：新增 `version!()` 宏（读取 Cargo.toml），main / REPL / 包管理器统一使用，消除硬编码版本串

### 测试
- lexer：新增 match/async 关键字与英文别名测试（32→22 结构重组，全绿）
- parser：新增 match 语句（简单/字段绑定/默认/命名绑定）与 await（表达式/标识符/语句）测试（37 全绿）
- codegen：新增 match 语句判别跳转与语法测试（26 全绿）
- e2e：`tests/integration/match_test.xy` 通过并接入 CI；`tests/integration/async_test.xy` 标记预期失败（待 v0.3.0 状态机）

### 修复
- parser 兼容 `=>` 箭头 token（原 lexer 将 `=>` 生成为单个 `箭头` token，parser 曾期望 `>`+`=` 两个 token）

## 版本概述

**玄语**（XY Language）是一门以中文为原生语法的编译型编程语言，基于 LLVM 构建，支持自举编译。本版本为 `v0.2.0-beta`，标志着自举验证通过：L2 编译器（XY 实现）已可由 L1（Rust）成功编译为可执行文件，且编译自身生成的 IR 与 L1 完全一致。

> 本项目原名 ZHCC，现正式更名为「玄语」。

**自举进度**：
| 阶段 | 描述 | 状态 |
|------|------|:--:|
| 阶段1 | L1 (Rust) 编译 L2 源码 → xyc.exe | ✅ 完成 |
| 阶段2 | xyc.exe 编译 L2 源码 → xyc2.exe | ✅ 完成 |
| 阶段3 | xyc2.exe ≡ xyc3.exe 等价验证 | ✅ 完成（IR 与 L1 完全一致） |

自举**阶段 3 已通过**：使用 L2 编译器编译自身源码生成 xyc2.exe，再编译得到 xyc3.exe，验证三个编译器的 IR 完全一致，自举能力完整。后续优化将编译容量上限从 7KB 提升至 21KB。

# 玄语编译器 v0.1.0-alpha 发布说明 (历史)

## 版本概述

**玄语**（XY Language）是一门以中文为原生语法的编译型编程语言，基于 LLVM 构建，支持自举编译。本版本为 `v0.1.0-alpha`，是玄语编译器的首个公开预览版本。

> 本项目原名 ZHCC，现正式更名为「玄语」。

**当前状态**：编译器已能够成功编译和运行 XY 程序，核心功能已完成，正在进行功能完善和性能优化。

---

## 主要功能

### 基础语法

- **变量定义**：支持带类型注解的变量定义
  ```xy
  定义 x: 整数 = 42
  定义 可变 y: 文本 = "Hello"
  ```

- **函数定义**：支持完整的函数签名和函数体
  ```xy
  函数 求和(a: 整数, b: 整数): 整数 {
      返回 a + b
  }
  ```

- **条件语句**：支持 `若...则...否则` 结构及嵌套
  ```xy
  若 分数 > 60 则 {
      打印("及格")
  } 否则若 分数 > 90 则 {
      打印("优秀")
  } 否则 {
      打印("不及格")
  }
  ```

- **循环语句**：支持计数循环和当循环
  ```xy
  // 计数循环
  循环 从 i 到 10 {
      打印整数(i)
  }
  
  // 当循环
  当 i < 10 {
      i = i + 1
  }
  ```

- **列表操作**：支持列表创建、索引访问和修改
  ```xy
  定义 我的列表 = rt_list_new()
  rt_list_append(我的列表, "元素")
  打印(我的列表[0])
  ```

- **复合赋值**：支持 `+=`、`-=`、`*=`、`/=`、`%=` 等复合赋值运算符
  ```xy
  x += 1
  y *= 2
  ```

### 数据类型

| XY 类型 | 说明         | LLVM 类型 |
| ------- | ------------ | --------- |
| 整数    | 有符号整型   | i64       |
| 浮点数  | 双精度浮点   | double    |
| 文本    | UTF-8 字符串 | i8\*      |
| 布尔    | 真/假        | i1        |
| 字符    | Unicode 字符 | i32       |
| 无返回  | void 函数    | void      |

### 高级特性

- **闭包与 Lambda**：支持完整的闭包实现，自动管理内存
- **尾调用优化**：尾递归函数自动优化，避免栈溢出
- **泛型函数**：支持类型参数，自动生成特化代码
- **中英双语关键字**：支持 `fn`/`if`/`return`/`let`/`loop` 等英文别名
- **错误提示国际化**：支持中/英/双语三种错误提示语言

## 技术栈

- **宿主语言**：Rust 1.70+
- **编译器后端**：LLVM 15+（使用 inkwell crate，后续将升级到更新版本）
- **运行时库**：C 语言实现
- **构建工具**：Cargo

### 编译流程

```
源代码 (.xy)
    │
    ▼
┌─────────────────┐
│  词法分析 (Lexer) │  Token 流
└─────────────────┘
    │
    ▼
┌─────────────────┐
│  语法解析 (Parser) │  AST
└─────────────────┘
    │
    ▼
┌─────────────────┐
│ 语义分析 (Sema)  │  类型检查/作用域
└─────────────────┘
    │
    ▼
┌─────────────────┐
│ 代码生成 (Codegen)│  LLVM IR
└─────────────────┘
    │
    ▼
┌─────────────────┐
│   LLVM 优化      │  优化后的 IR
└─────────────────┘
    │
    ▼
┌─────────────────┐
│   LLVM 编译      │  目标文件 (.o)
└─────────────────┘
    │
    ▼
┌─────────────────┐
│   链接 (Link)    │  可执行文件
└─────────────────┘
    │
    ▼
┌─────────────────┐
│   C 运行时库      │  runtime.c
└─────────────────┘
```

## 安装步骤

### 环境要求

- Rust 1.70+
- LLVM 15+（含 llvm-config，后续将升级到更新版本）
- clang/clang++ 编译器
- Windows PowerShell / Linux bash

### 编译项目

```bash
# 克隆仓库
git clone https://github.com/xuanyu-lang/xuanyu.git
cd xuanyu

# 编译项目（开发模式）
cargo build

# 编译项目（发布模式，推荐用于生产环境）
cargo build --release
```

### 使用方法

```bash
# 运行 Hello World
cargo run -- examples/hello.xy --run

# 仅生成 LLVM IR
cargo run -- examples/hello.xy --ir

# 运行所有测试
cargo test
```

## 使用示例

### Hello World 示例

创建文件 `hello.xy`：

```xy
/**
 * @file hello.xy
 * @brief 玄语测试程序
 */

函数 主() : 整数 {
    定义 分数: 整数 = 85
    
    打印整数(分数)
    打印("\n")
    
    若 分数 > 60 则 {
        打印("Pass\n")
    } 否则 {
        打印("Fail\n")
    }
    
    返回 0
}
```

运行命令：

```bash
cargo run -- hello.xy --run
```

输出结果：

```
85
Pass
```
