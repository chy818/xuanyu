# 玄语（XY Language）

**玄语** 是一款以中文为原生语法的编译型编程语言，后端生成 LLVM IR 文本（再由 LLVM 工具链降级为机器码），支持自举编译。

> 本项目原名 ZHCC，现正式更名为「玄语」。编译器已能成功编译和运行 XY 程序，欢迎参与贡献！

## 快速开始

### 环境要求

- Rust 1.70+
- LLVM 15+（后端工具链，含 `llc`/`clang`；编译器本身生成 IR 文本，不依赖 inkwell）
- clang/clang++ 编译器
- Windows PowerShell / Linux bash

### 编译运行

```bash
# 编译项目
cargo build --release

# 运行 Hello World
cargo run -- examples/hello.xy --run

# 仅生成 IR
cargo run -- examples/hello.xy --ir

# 运行测试
cargo test
```

### L1 vs L2 编译器说明

| 编译器 | 实现语言 | 用途 | 状态 |
|--------|---------|------|------|
| **L1 (src/)** | Rust | 宿主编译器，用于编译 XY 源代码 | 生产就绪 |
| **L2 (src/compiler_v2/)** | XY | 自举编译器，用 XY 自身实现 | 自举验证通过 |

**自举流程**：
```
Phase 1: Rust (L1) 编译 XY 源代码 → 生成可执行文件
Phase 2: XY (L2) 编译器编译自身源代码 → 验证自举成功（IR 与 L1 一致）
```

L1 编译器是当前生产使用的编译器，L2 编译器是为了验证语言自举能力而开发的。

## 语言特性

### 基础语法

```xy
// 注释使用中文

函数 主(): 整数 {
    定义 消息: 文本 = "Hello, World!"
    打印(消息)
    返回 0
}
```

### 控制流

```xy
// 条件判断
若 年龄 >= 18 则 {
    打印("成年人")
} 否则 {
    打印("未成年")
}

// 计数循环
循环 从 i 到 10 {
    打印整数(i)
}

// 当循环
当 i < 10 {
    打印(i)
    i = i + 1
}
```

### 函数定义

```xy
函数 求和(a: 整数, b: 整数): 整数 {
    返回 a + b
}

函数 打招呼(名字: 文本) {
    打印("你好, " + 名字)
}
```

### 数据类型

| XY 类型 | 关键字              | 说明           | LLVM 类型 |
| ------- | ------------------- | -------------- | --------- |
| 整数    | `整数`/`int`        | 有符号整型     | i64       |
| 长整数  | `长整数`            | 有符号扩展整形 | i64       |
| 浮点数  | `浮点数`/`float`    | 浮点数         | double    |
| 双精度  | `双精度`/`double`   | 双精度浮点     | double    |
| 文本    | `文本`/`string`     | UTF-8 字符串   | i8\*      |
| 布尔    | `布尔`/`bool`       | 真/假          | i1        |
| 字符    | `字符`/`char`       | Unicode 字符   | i32       |
| 无返回  | `无返回`/`void`     | void 函数      | void      |
| 指针    | `指针`/`ptr`        | 内存指针       | i8\*      |
| 列表    | `列表`/`list`       | 动态数组       | i8\*      |
| 或许    | `或许`/`Option`     | 可选值         | i8\*      |

> 注：实际 LLVM 整数统一为 `i64`、浮点统一为 `double`（见 `src/codegen/codegen.rs` 的 `translate_type`）。布尔在 LLVM 层面按 `i64` 存储。

### 闭包与 Lambda

闭包是一种可以捕获外部作用域变量的匿名函数。玄语支持完整的闭包实现。

#### 基本语法

```xy
函数 主(): 整数 {
    定义 f: 函数 = 函数(x) => x + 1
    打印整数(f(5))  // 输出 6
    返回 0
}
```

#### 闭包捕获外部变量

```xy
函数 主(): 整数 {
    定义 x: 整数 = 10

    // 闭包捕获外部变量 x
    定义 加法: 函数 = 函数(y) => x + y

    打印整数(加法(5))  // 输出 15
    返回 0
}
```

#### 闭包捕获与内存

玄语闭包通过「捕获变量按值传入」实现，不分配堆内存：
- 捕获的变量作为额外参数传给 lambda 函数
- lambda 以函数指针形式参与调用（LLVM `ptrtoint` 转 `i64`）
- 生命周期与普通函数一致，无需手动释放

#### 闭包实现（高级）

闭包在 LLVM IR 中的实现方式：
```
lambda 被降级为独立的内部函数，捕获变量作为额外参数按值传入
调用点通过 ptrtoint 取得函数指针（i64），再按捕获参数调用
```

### 泛型函数

泛型函数支持类型参数，使代码更加通用和复用。

#### 基本语法

```xy
// 类型参数用尖括号包裹
函数 交换<T>(a: T, b: T): T {
    定义 temp: T = a
    a = b
    b = temp
    返回 temp
}

函数 主(): 整数 {
    定义 x: 整数 = 10
    定义 y: 整数 = 20
    交换(x, y)
    打印整数(y)  // 输出 10
    返回 0
}
```

> 说明：类型参数名请使用普通标识符（如 `T`），不能使用 `类型` 等关键字。

### 尾递归优化

玄语编译器支持尾调用优化，尾递归函数不会导致栈溢出。

#### 基本语法

```xy
函数 factorial(n: 整数, acc: 整数): 整数 {
    若 n == 0 则 {
        返回 acc
    }
    返回 factorial(n - 1, n * acc)  // 尾递归，自动优化
}

函数 主(): 整数 {
    打印整数(factorial(5, 1))  // 输出 120
    返回 0
}
```

#### 尾调用优化原理

编译器检测到尾递归调用时，自动将其转换为：
1. 参数更新
2. 跳转到函数入口

这样可以避免栈帧累积，实现真正的常数空间复杂度。

#### Fibonacci 示例

```xy
函数 fibonacci(n: 整数, a: 整数, b: 整数): 整数 {
    若 n == 0 则 {
        返回 a
    }
    若 n == 1 则 {
        返回 b
    }
    返回 fibonacci(n - 1, b, a + b)  // 尾递归
}

函数 主(): 整数 {
    打印整数(fibonacci(10, 0, 1))  // 输出 55
    返回 0
}
```

### 宏系统

宏是一种在编译期展开代码的元编程能力。玄语支持声明式宏，在词法分析之后、语法分析之前完成展开。

#### 定义与调用

```xy
// 定义宏：宏 名称 (形参) 展开 { 模板 }
宏 两倍 (a) 展开 { a + a }
宏 问候 展开 { 打印("你好") }

函数 主(): 整数 {
    定义 x: 整数 = 两倍(21)   // 展开后: 定义 x: 整数 = 21 + 21
    问候()
    返回 0
}
```

宏调用在展开时会按位置将实参替换为形参标识符，支持嵌套括号、多参数、以及宏体内的递归调用展开。宏定义与调用无需额外前缀，同名标识符优先按宏展开。

### 中英双语关键字

玄语编译器支持中英文关键字等价使用：

```xy
// 中文写法
函数 加法(a: 整数, b: 整数): 整数 {
    返回 a + b
}

// 英文别名写法
fn add(a: int, b: int) -> int {
    return a + b
}

// 中英文混用（也是允许的）
fn multiply(x: int, y: int): 整数 {
    若 x == 0 || y == 0 则 {
        返回 0
    }
    return x * y
}
```

支持的英文关键字别名：`if`/`fn`/`return`/`let`/`loop`/`struct`/`enum` 等，详见 [编码规范](docs/编码规范.md)。

### 错误提示国际化

玄语编译器支持中/英/双语三种错误提示语言：

```bash
# 设置错误语言（默认中文）
$ XY_ERROR_LANG=zh cargo run -- examples/hello.xy --run

# 英文错误
$ XY_ERROR_LANG=en cargo run -- examples/hello.xy --run

# 中英双语
$ XY_ERROR_LANG=both cargo run -- examples/hello.xy --run
```

## 技术架构

```
源代码 (.xy)
    │
    ▼
┌─────────────────┐
│  词法分析 (Lexer) │  Token 流
│  Rust lexer.rs  │
└─────────────────┘
    │
    ▼
┌─────────────────┐
│  语法解析 (Parser) │  AST
│  Rust parser.rs │
└─────────────────┘
    │
    ▼
┌─────────────────┐
│ 语义分析 (Sema)  │  类型检查/作用域
│  Rust sema.rs   │
└─────────────────┘
    │
    ▼
┌─────────────────┐
│  代码生成 (Codegen)│  LLVM IR 文本
│  Rust codegen.rs│   (i8* 指针规范)
└─────────────────┘
    │
    ▼
┌─────────────────┐
│   LLVM 优化      │  优化后的 IR
│   llc -O2       │
└─────────────────┘
    │
    ▼
┌─────────────────┐
│   LLVM 编译      │  目标文件 (.o)
│   llc -filetype=obj
└─────────────────┘
    │
    ▼
┌─────────────────┐
│   链接 (Link)    │  可执行文件
│   clang/lld     │
└─────────────────┘
    │
    ▼
┌─────────────────┐
│   C 运行时库      │  runtime.c
│   打印/内存/IO   │
└─────────────────┘
```

> 注：编译器直接生成 LLVM IR 文本（opaque pointers），由外部 `llc` 目标代码 + `clang` 链接 runtime.c 完成后端降级。`inkwell` 仅为可选特性（`--features llvm`），默认未启用。
