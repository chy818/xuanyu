# 玄语标准库 (XY Standard Library)

玄语标准库提供了常用的数据结构和工具函数，帮助开发者快速构建应用程序。

## 模块列表

### 📝 string - 字符串处理 (`std/string.xy`)

提供字符串操作的工具函数。

| 函数 | 描述 |
|------|------|
| `字符串长度(文本)` | 计算字符串长度 |
| `字符串拼接(甲, 乙)` | 拼接两个字符串 |
| `字符串比较(甲, 乙)` | 比较两个字符串 |
| `字符串复制(目标, 源)` | 复制字符串 |
| `查找字符(文本, 字符)` | 查找字符位置（返回位置，未找到 -1） |
| `字符串转整数(文本)` | 字符串转整数 |
| `整数转字符串(数值)` | 整数转字符串 |
| `字符串为空(文本)` | 检查字符串是否为空 |
| `字符串以开头(文本, 前缀)` | 检查是否以指定前缀开头 |

### 📊 array - 数组操作

提供数组操作的工具函数。

| 函数 | 描述 |
|------|------|
| `数组长度(数组)` | 获取数组长度 |
| `数组创建(大小)` | 创建指定大小的数组 |
| `数组添加(数组, 元素)` | 追加元素，返回新长度 |
| `数组获取(数组, 索引)` | 获取指定索引的元素 |

> 说明：玄语内建 `列表`（`列表长度`/`列表添加`/`列表获取`/`创建列表`）用得更多。

### 🔢 math - 数学工具

提供数学运算的工具函数。

| 函数 | 描述 |
|------|------|
| `绝对值(数值)` | 计算绝对值 |
| `最大公约数(甲, 乙)` | 计算最大公约数 |

### 📥 io - 输入输出

提供输入输出的工具函数。

| 函数 | 描述 |
|------|------|
| `打印整数(数值)` | 打印整数 |
| `打印文本(文本)` | 打印文本 |
| `打印布尔值(数值)` | 打印布尔值 |
| `打印换行()` | 打印换行 |
| `打印标题(标题)` | 打印标题（正文后换行） |
| `打印行(文本)` | 打印文本并换行 |
| `打印格式化(格式, 参数)` | 打印格式化文本（支持 %d） |
| `读取整数()` | 读取整数 |
| `读取文本()` | 读取一行文本 |
| `读取文件(路径)` | 读取文件全部内容 |
| `写入文件(路径, 内容)` | 写入文件 |
| `文件存在(路径)` | 检查文件是否存在 |
| `删除文件(路径)` | 删除文件 |
| `追加文件(路径, 内容)` | 追加内容到文件 |
| `复制文件(源路径, 目标路径)` | 复制文件 |
| `执行命令(命令)` | 执行系统命令 |
| `命令输出(命令)` | 执行命令并获取输出 |

## 使用示例

```xy
// 引入标准库
引入 "std/string"
引入 "std/io"

函数 主(): 整数 {
    // 字符串操作
    定义 文本 = "你好，玄语！"
    打印整数(字符串长度(文本))
    打印("\n")

    // 数学运算
    打印整数(绝对值(-10))

    返回 0
}
```
